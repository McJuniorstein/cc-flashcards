## Coverage gaps still open after this batch

- **Rule-Based Access Control** — not defined in CNSSI 4009 or any existing source. Would need a different glossary (CNSSI itself only defines "rule-based security policy", which is adjacent but not the same).
- **Packet, Frame, Port (as networking terms)** — CNSSI 4009 only defines compound terms ("packet sniffer", "port scan"). Adding NIST SP 800-94 or RFC-level sources would unblock.
- **VLAN, Network Segmentation** — not in CNSSI 4009. Likely covered by NIST SP 800-125B (Virtualization) or 800-41 (Firewalls). Future source-addition pass.

These are tracked for a follow-up session; not in scope for this PR.
